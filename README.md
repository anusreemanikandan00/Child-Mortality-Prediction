#  Child Mortality Prediction Using Machine Learning

##  Project Overview

Child mortality is an important public health and social issue influenced by various demographic, socioeconomic, healthcare, and environmental factors.

The **Child Mortality Prediction** project is a machine learning-based system developed to analyze relevant factors and predict child mortality outcomes using historical data.

The project follows a complete machine learning workflow, including data collection, preprocessing, exploratory data analysis, model training, evaluation, and prediction.

The aim of this project is to demonstrate how machine learning can be applied to analyze patterns in child mortality data and develop predictive models.

---

##  Problem Statement

Child mortality can be influenced by several interconnected factors, making it difficult to analyze using a single variable.

Traditional analysis of historical data may require significant time and effort. Machine learning can help identify patterns and relationships among multiple factors in a dataset.

This project aims to develop a machine learning-based prediction system that analyzes relevant features and predicts child mortality outcomes.

---

##  Objectives

The main objectives of this project are:

- To analyze factors associated with child mortality.
- To preprocess and prepare the dataset for machine learning.
- To explore relationships between different variables.
- To identify important features for prediction.
- To train different machine learning models.
- To evaluate the performance of the trained models.
- To compare the prediction results.
- To generate predictions based on the input data.

---

##  Dataset

The dataset used for this project contains relevant demographic, socioeconomic, healthcare, and other factors associated with child mortality.

The dataset is processed before applying machine learning algorithms.

### Data Processing Steps

1. Load the dataset.
2. Understand the dataset structure.
3. Check for missing values.
4. Handle and preprocess the data.
5. Perform exploratory data analysis.
6. Select relevant features.
7. Split the data into training and testing sets.
8. Train machine learning models.
9. Evaluate model performance.
10. Generate predictions.

##  Machine Learning Algorithms

The project uses different machine learning algorithms to analyze the dataset and generate predictions.

The algorithms used include:

- Linear Regression
- Random Forest
- Decision Tree
- Logistic Regression
- AdaBoost
- Gradient Boosting
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes

Each algorithm is trained and evaluated to understand its performance on the given dataset.

---

##  Model Evaluation

The performance of the machine learning models is evaluated using suitable evaluation metrics.

The main metrics used in the project are:

- **Accuracy** – Measures the percentage of correctly predicted results.
- **R² Score** – Measures how well the model explains the variation in the target variable.

The results of the different models are compared to understand their performance.
